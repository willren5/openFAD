# openFAD v0.1.7

本版本修正开源许可证与 release manifest 元数据一致性，并把官网 `/openfad/downloads/` 的下载与校验页纳入源码。

## 下载

最终以本 release 附件中的 `release-manifest.json` 和 `SHA256SUMS` 为准。

| Artifact | 类型 | 状态 | SHA256 |
| --- | --- | --- | --- |
| `openfad-cover-machine-0.1.7.zip` | 浏览器网页包 | Tested | 见 `SHA256SUMS` / `release-manifest.json` |
| `openfad-mv-studio-0.1.7.zip` | 浏览器网页包 | Tested | 见 `SHA256SUMS` / `release-manifest.json` |
| `openfad-motion-batch-source-0.1.7.zip` | 源码包 | Preview | 见 `SHA256SUMS` / `release-manifest.json` |
| `openFAD-Motion-Batch-0.1.7-x64.exe` | Windows 桌面包 | Preview | 见 `SHA256SUMS` / `release-manifest.json` |
| `openFAD-Motion-Batch-0.1.7-arm64.dmg` | macOS arm64 桌面包 | Preview | 见 `SHA256SUMS` / `release-manifest.json` |

## 修正

- `LICENSE`、`package.json`、`package-lock.json`、`TRADEMARKS.md` 和 `release-manifest.json` 统一为 `AGPL-3.0-or-later`。
- release workflow 不再固定读取 `v0.1.6` release notes，而是按 tag 读取 `docs/release/<tag>.zh-CN.md`。
- 官网静态下载页源码包含在 `site/downloads/index.html`，避免线上热修与 GitHub 源码分叉。

## 快速使用

Cover Machine：

1. 打开官网：`https://fadrecords.com/openfad/`
2. 点击“做封面”。
3. 点击“打开示例”，替换歌名、艺人和图片。
4. 导出封面 JPG 或透明 PNG。

MV Studio：

1. 打开官网：`https://fadrecords.com/openfad/`
2. 点击“做音乐可视化”。
3. 点击“打开示例”，选择视觉系统并预览。
4. 换成自己的素材后导出视频。

Motion Batch：

1. 打开官网：`https://fadrecords.com/openfad/`
2. 按系统点击“下载 Windows”或“下载 macOS”。
3. 在本机打开下载的 Motion Batch 桌面包。
4. 选择输入视频和输出目录，处理 Apple Music 动态封面裁切。

## 信任边界

- Cover Machine 和 MV Studio 是浏览器网页包；测试覆盖导出触发和失败路径，但不宣称所有系统的浏览器保存行为完全一致。
- Windows 包内置 pinned BtbN FFmpeg/FFprobe，并在打包前校验大小和 SHA256；`Stable` 仍需要 Windows full-render packaged-runtime smoke evidence。
- macOS arm64 DMG 是 unsigned Preview；`Stable` 需要独立 macOS packaged-runtime smoke evidence。
- AGPL-3.0-or-later 只覆盖源码，不授权 FAD Records 品牌、Logo、艺人素材或真实发行资产。请阅读 `LICENSE` 和 `TRADEMARKS.md`。
