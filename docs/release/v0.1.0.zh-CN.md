# openFAD v0.1.0

这是 openFAD 的中文优先开源首发候选版本，包含三个公开安全工具：

- Cover Machine：浏览器网页包，用于制作封面、社媒图和透明图层。
- MV Studio：浏览器网页包，用于制作本地音乐视觉和 visualizer。
- Motion Batch：源码包，用于本地 UI / CLI / QC 验证；当前不是 Windows 可执行安装包。

## 快速使用

Cover Machine：

1. 下载并解压 `openfad-cover-machine-0.1.0.zip`。
2. 打开 `index.html`。
3. 点击“打开示例”，替换歌名、艺人和图片。
4. 导出封面 JPG 或透明 PNG。

MV Studio：

1. 下载并解压 `openfad-mv-studio-0.1.0.zip`。
2. 打开 `index.html`。
3. 点击“打开示例”，选择视觉系统并预览。
4. 换成自己的素材后导出视频。

Motion Batch：

1. 下载并解压 `openfad-motion-batch-source-0.1.0.zip`。
2. 进入解压目录。
3. 运行 `npm ci`。
4. 运行 `npm run ui` 打开本地界面，或用 CLI / QC-only 路径做深度验证。

## 验证

深度用户可以从仓库源码复现 release gate：

```bash
npm ci
npm ci --prefix apps/motion-batch
npm run scan:public
npm test
npm run package:web
npm run checksums
npm run release:manifest
```

## 信任边界

- Cover Machine 和 MV Studio 是浏览器网页包；测试覆盖导出触发和失败路径，但不宣称浏览器下载提示之后的系统保存行为已被所有系统验证。
- Motion Batch 当前开放的是源码包，状态为 Preview；Windows 可执行 runtime 需要 full-render smoke evidence 后才能标记为可信下载。
- 代码开源不代表 FAD Records 品牌、Logo、艺人素材或真实发行资产开源。请阅读 `LICENSE`、`NOTICE` 和 `TRADEMARKS.md`。
- 若 `release-manifest.json` 的 `verification.ciRunUrl` 为空，请只引用本地验证证据，不要宣称 CI 已完成。

## 已知限制

- 浏览器导出和录制行为可能因渲染器不同而变化。
- Motion Batch 的重渲染工作在本地执行，不在 fadrecords.com 上运行。
- Motion Batch Windows executable 未包含在本次可信 runtime 下载范围内。
