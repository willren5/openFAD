# openFAD v0.1.5

本版本修正官网 Motion Batch 下载链路：`/openfad/` 不再把普通用户导向源码 zip，而是提供 Windows 和 macOS 的桌面下载包。相比 `v0.1.4`，本版本还修正 Windows packaged-runtime smoke 在 CI 中依赖打开 Explorer 的发布门禁问题。

## 下载

最终以本 release 附件中的 `release-manifest.json` 和 `SHA256SUMS` 为准。

| Artifact | 类型 | 状态 | SHA256 |
| --- | --- | --- | --- |
| `openfad-cover-machine-0.1.5.zip` | 浏览器网页包 | Tested | 见 `SHA256SUMS` / `release-manifest.json` |
| `openfad-mv-studio-0.1.5.zip` | 浏览器网页包 | Tested | 见 `SHA256SUMS` / `release-manifest.json` |
| `openfad-motion-batch-source-0.1.5.zip` | 源码包 | Preview | 见 `SHA256SUMS` / `release-manifest.json` |
| `openFAD-Motion-Batch-0.1.5-x64.exe` | Windows 桌面包 | Preview | 见 `SHA256SUMS` / `release-manifest.json` |
| `openFAD-Motion-Batch-0.1.5-arm64.dmg` | macOS arm64 桌面包 | Preview | 见 `SHA256SUMS` / `release-manifest.json` |

## 快速使用

Cover Machine：

1. 打开官网：`https://fadrecords.com/openfad/`
2. 点击“做封面”。
3. 点击“打开示例”，替换歌名、艺人和图片。
4. 导出封面 JPG 或透明 PNG。

MV Studio：

1. 打开官网：`https://fadrecords.com/openfad/`
2. 点击“做音乐可视化”。
3. 点击“打开示例”，选择视觉系统并预览。
4. 换成自己的素材后导出视频。

Motion Batch：

1. 打开官网：`https://fadrecords.com/openfad/`
2. 按系统点击“下载 Windows”或“下载 macOS”。
3. 在本机打开下载的 Motion Batch 桌面包。
4. 选择输入视频和输出目录，处理 Apple Music 动态封面裁切。

## 验证

本版本发布前需要复现：

```bash
npm ci
npm ci --prefix apps/motion-batch
npm run scan:public
npm test
npm run package:web
npm run package:motion:win
npm run package:motion:mac
npm run checksums
npm run release:manifest
```

## 信任边界

- Cover Machine 和 MV Studio 是浏览器网页包；测试覆盖导出触发和失败路径，但不宣称所有系统的浏览器保存行为完全一致。
- Windows 包内置 pinned BtbN FFmpeg/FFprobe，并在打包前校验大小和 SHA256；`Stable` 仍需要 Windows full-render packaged-runtime smoke evidence。
- macOS arm64 DMG 是 unsigned Preview；`Stable` 需要独立 macOS packaged-runtime smoke evidence。
