# openFAD v0.1.1

这是 openFAD 的中文优先可信开源首发版本。相比 v0.1.0，本版本修正官网分发链路：Motion Batch 不再要求普通用户进入 GitHub Releases 自己找文件，官网 `/openfad/` 会直接提供下载。

## 下载

最终以本 release 附件中的 `release-manifest.json` 和 `SHA256SUMS` 为准。

| Artifact | 类型 | 状态 | SHA256 |
| --- | --- | --- | --- |
| `openfad-cover-machine-0.1.1.zip` | 浏览器网页包 | Tested | 见 `SHA256SUMS` / `release-manifest.json` |
| `openfad-mv-studio-0.1.1.zip` | 浏览器网页包 | Tested | 见 `SHA256SUMS` / `release-manifest.json` |
| `openfad-motion-batch-source-0.1.1.zip` | 源码包 | Preview | 见 `SHA256SUMS` / `release-manifest.json` |

## 快速使用

Cover Machine：

1. 打开官网：`https://fadrecords.com/openfad/`
2. 点击“做封面”。
3. 点击“打开示例”，替换歌名、艺人和图片。
4. 导出封面 JPG 或透明 PNG。

MV Studio：

1. 打开官网：`https://fadrecords.com/openfad/`
2. 点击“做音乐可视化”。
3. 点击“打开示例”，选择视觉系统并预览。
4. 换成自己的素材后导出视频。

Motion Batch：

1. 打开官网：`https://fadrecords.com/openfad/`
2. 点击“下载裁切工具”。
3. 解压 `openfad-motion-batch-source-0.1.1.zip`。
4. 按包内 README 打开本地界面，处理 Apple Music 动态封面裁切。
