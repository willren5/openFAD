# openFAD

openFAD is a Chinese-first open-source creative toolkit by FAD Records for music cover art, visualizers, and motion-cover delivery.

The primary documentation is Simplified Chinese. This English file is a secondary orientation page.

## Tools

- Cover Machine: cover art and release visual export.
- MV Studio: local-first music visualizer.
- Motion Batch: Apple Music motion-cover delivery helper with QC reports.

## Trust Surface

Each release should include source, tests, checksums, release manifest, and dated verification notes.
