# Motion Batch 快速开始

Motion Batch 是本地批处理工具，不是 fadrecords.com 上的在线渲染服务。

## 第一次成功路径

1. 进入 `apps/motion-batch`。
2. 运行 `npm ci`。
3. 运行 `npm run ui`。
4. 打开 `http://127.0.0.1:4387`。
5. 选择一个方形 motion cover 视频，或选择包含多个视频的文件夹。
6. 选择一个空输出文件夹。
7. 保持默认 `auto` 帧率、`50M` 码率、`mp4` 容器。
8. 点击“开始处理”。

## 成功标准

- 队列状态变为完成。
- 输出文件夹里出现 `1x1`、`3x4`、安全区预览 PNG、JSON 报告和 HTML 报告。
- 报告里显示的 QC 结果和下载状态可被复核。

## 第一次排错

- 如果看不到 UI：确认 `npm ci` 成功，再重新运行 `npm run ui`。
- 如果找不到 FFmpeg：安装 `ffmpeg` 和 `ffprobe`，或在 UI/CLI 中填写完整路径。
- 如果输出已存在：换空输出文件夹。
- 如果报告显示失败：先看报告里的中文恢复建议，再决定是否重跑。

## 轻用户提示

这个工具的默认目标是“先跑通一次，再谈调整参数”。如果你只是想验证流程，不要先改 overwrite、编码器或高级 CLI 选项。
