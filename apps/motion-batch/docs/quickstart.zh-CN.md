# Motion Batch 快速开始

1. 进入 `apps/motion-batch`。
2. 运行 `npm ci`。
3. 运行 `npm run ui`。
4. 打开 `http://127.0.0.1:4387`。
5. 选择一个方形 motion cover 视频，或选择包含多个视频的文件夹。
6. 选择一个输出文件夹。
7. 点击开始处理。

成功标准：队列显示完成，输出文件夹里出现 `1x1`、`3x4`、预览 PNG、JSON 报告和 HTML 报告。

如果你不确定设置，保留默认值：`scale-fill`、`auto` 帧率、`50M` 码率、`mp4` 容器、`auto` encoder。
