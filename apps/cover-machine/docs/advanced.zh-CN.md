# Cover Machine 高级模式

高级设置不是轻用户的必读路径。它用于控制字体、字号、字距、背景裁切、Logo、混合模式、安全区、透明图层、项目 JSON 和自定义预设。

## 项目和预设

- 自动保存和自定义预设保存在当前浏览器本地。
- 项目 JSON 用于继续编辑和复查，不是最终 release manifest。
- 大图片可以参与导出，但可能不会写入自动保存或自定义预设。

## 使用分析

公开版默认“分析: 关”。开启后只发送使用事件，不上传封面图片、项目 JSON 或导出文件。关闭分析不会影响本地自动保存。

## 验证命令

在仓库根目录运行：

```bash
npm run test:cover
npm run scan:public
```
